# Kodluyoruz Front-End Dersleri
## Birinci Ödev
* CSS ile sayfa tasarımı

- Eğitimlerimiz kapsamında konseptini bizim belirleyeceğimiz basit bir sayfa tasarımı ödevi verildi.

- Bu sayfanın CSS ile tasarımında dersler kapsamında öğrendiğimiz kavramları kullanmaya çalıştım.

- Tasarımım tek bir sayfadan oluşuyor. Belki ilerdeki ödevlere göre geliştirebilirim. 

- Bir sinefilin bloğu olarak düşünüp tasarladım.

## Tasarım Detayları

- Sayfa arka planı çiğ beyaz yerine göz yormayan ve metin renkleriyle uyumlu açık bir ton olarak tasarlandı. 

- Görsel olarak dikkat çekici olması adına metni ikiye bölüp ortasına görsel yerleştirmeyi tercih ettim.

- Yazı stili olarak göze yumuşak göründüğünden başlıkta Bahie Waonid, okunabilirlik açısından kalan metinlerdeyse Georgia fontu serif şekilde tercih edildi. Başlıklarda görsel bütünlük için aynı fonta dikkat edildi.

- Görsel öge havada duruyor gibi algılanmasın diye küçük bir border içine alındı ve daha doyurucu bir araştırma deneyimi için IMDb linki görsel içine yerleştirildi.

- Okuyucuda merak uyandırmak için bloga konu olan yönetmenin adına yine IMDb linki verildi ve ekstra filmler de eklendi. Link rengi de görsel bütünlük açısından çiğ durmaması için başlıkla yanı renkte verildi. Sayfanın en önemli yeri olmadığı için daha belirgin ve farklı bir renk tercih etmek istemedim.

## 🚀 Installation (Kurulum)

- Projeyi yerel bilgisayarınıza klonlamak ve çalıştırmak için aşağıdaki adımları takip edebilirsiniz:
1. Bu depoyu (repository) bilgisayarınıza klonlayın: git clone [https://github.com/inci94/kodluyoruzilkrepo.git](https://github.com/inci94/kodluyoruzilkrepo.git)
2. Proje dizinine gidin cd kodluyoruzilkrepo/css.odev1

- İkimci yöntem olarak açmak isterseniz;
1. Bu sayfanın üst tarafında yer alan yeşil **`Code`** butonuna tıklayın.
2. **`Download ZIP`** seçeneğine tıklayarak dosyayı bilgisayarınıza indirin.
3. İnen ZIP dosyasını klasöre çıkartın.

### 🛠️ Usage (Kullanım)
1. css.odev1 klasörü içindeki index.html dosyasına çift tıklayarak varsayılan tarayıcınızda açabilirsiniz.

2. Alternatif olarak, VS Code kullanıyorsanız projenizi açıp Live Server eklentisi ile tarayıcıda canlı olarak görüntüleyebilirsiniz.
