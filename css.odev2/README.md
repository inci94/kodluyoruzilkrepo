# Kodluyoruz Front-End Dersleri 
## İkinci Ödev
* Google Sayfası Tasarımı
- Eğitimlerimizde CSS tasarımındaki posizyonlar, grid yapısı, seçiciler gibi birçok konunun mantıksal yerleşimlerini pratik yapmak amacıyla Google'ın 1998'deki ana sayfa tasarımını inceleyip benzerini hatta yapabiliyorsak birebir aynısını yapmaya çalıştık.

## 🔍 Tasarımın Detayları
- Sayfa arka plan rengi ve butonların bulunduğu alanların rengini ayrı ayrı kutular olarak düşünüp tasarımın CSS ayarlarını ona göre yazmaya çalıştım. 
- Bu kutuların içine butonları yerleştirdim ve onların da konumlarını hazırladığım ayrı CSS dosyası içinde tasarımın orijinaline benzer şekilde konumlandırmaya çalıştım.

## Kaynaklar
- w3Schools CSS tasarım eğitimlerinden yararlandım
- Arayüz & DOM İncelemesi: Tarayıcı Geliştirici Araçları (`F12` / Inspect Element)
- Kaynak Kodu Analizi: Sayfa Kaynağını Görüntüle (`Ctrl + U`)

## 🚀 Installation (Kurulum)

- Projeyi yerel bilgisayarınıza klonlamak ve çalıştırmak için aşağıdaki adımları takip edebilirsiniz:
1. Bu depoyu (repository) bilgisayarınıza klonlayın: git clone [https://github.com/inci94/kodluyoruzilkrepo.git](https://github.com/inci94/kodluyoruzilkrepo.git)
2. Proje dizinine gidin cd kodluyoruzilkrepo/css.odev2

- İkimci yöntem olarak açmak isterseniz
1. Bu sayfanın üst tarafında yer alan yeşil **`Code`** butonuna tıklayın.
2. **`Download ZIP`** seçeneğine tıklayarak dosyayı bilgisayarınıza indirin.
3. İnen ZIP dosyasını klasöre çıkartın.

### 🛠️ Usage (Kullanım)
1. css.odev2 klasörü içindeki index.html dosyasına çift tıklayarak varsayılan tarayıcınızda açabilirsiniz.

2. Alternatif olarak, VS Code kullanıyorsanız projenizi açıp Live Server eklentisi ile tarayıcıda canlı olarak görüntüleyebilirsiniz.
