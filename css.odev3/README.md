# CSS Ödev 3: Google Anasayfa Tasarımı
Kodluyoruz Başlangıç Seviye Front-End Web Patikası kapsamında, CSS kurallarını pekiştirmek amacıyla Google anasayfası yeniden tasarlandı.

## Kullanılan Teknolojiler
- HTML5
- CSS3 (Flexbox, `border-radius`, `box-shadow`)


### Üst Bölüm
- Images, Gmail, uygulama (waffle) menüsü ve profil resmi sağ tarafa taşındı.
- Profil resmi `border-radius` ile yuvarlatıldı.

### Arama Alanı
- Arama alanının kenarları `border-radius` ile yuvarlatıldı.
- Yazı yazılan alanın kenarlığı kaldırıldı ve genişliği `480px` olarak ayarlandı.
- Assets klasöründeki arama ikonu (SVG) tarayıcıda çalışmadığı için yerine farklı bir SVG kodu kullanıldı.
- Sesle arama ikonu PNG olarak eklendi. Boyut ve konum ayarları için tarayıcının İncele (Inspect) aracı kullanıldı.

### Butonlar
- "Google Search" ve "I'm Feeling Lucky" butonları ortalandı, arama alanına ve birbirlerine göre boşluk verildi.
- Kenarlık `1px solid #f2f2f2`, yazı tipi Arial, yazı rengi `#5f6368`, yazı boyutu `14px`, yükseklik `36px` olarak ayarlandı.
- Butonlara arama alanındakiyle aynı gölge verildi.

### Footer
- Arka plan rengi `#f2f2f2` yapıldı.
- Liste noktaları kaldırıldı.
